# mirefieldBot
Bot du roleplay Mirefieldn réalisé dans un cadre communautaire. Ce projet tourne sous NodeJS/Javascript.

DiscordJS est la première librairie qui a été utilisé, suivi d'une librairie externe pour l'utilisation d'un jukebox capable d'être employé lors d'un vocal Discord pour jouer une musique Youtube. 

Le bot contient plusieurs commandes qui sont les suivantes:

- Liste des utilisateurs enregistrées
- Carte de personnage avec les compétences personnalisées pour chacun d'entre eux
- Liste complètes de l'ensemble des personnages de joueurs avec système de pagination 
- Possibilité d'ajouter, modifier ou supprimer un personnage existant 
Jouer une musique en vocal avec d'autres joueurs
